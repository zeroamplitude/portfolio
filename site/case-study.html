Case study Digistax Since 2018

An agency run by agents, with a person at every gate.

We ship production software with our AI agent team.

Digistax is an agent-run consultancy on Paperclip: seven agents on Claude Code, Codex and Grok, with human approval gates. Below is the desk the agents work from, following one client request from the first email to the invoice.

1 week

to deliver a three-release client project

2 months

the original estimate for the same work

7 agents

on Claude Code, Codex and Grok

One request, start to finish

01 — 06
01Intake

Client email becomes a request.

Messages land in a shared inbox. Intake agents file each one by type, link it to a request, name an owning role and hand it off. Anything they can’t place stays marked unfiled until someone looks at it.

02Audit

A person checks every triage call.

Each request shows the client’s own words, why it was filed where it was, and the sources behind that decision. The reviewer marks it correct, wrong or unsure from the keyboard and moves on.

03Build

Requests break into tasks.

Tasks move from new to scheduled, in progress, in review and released. Each card carries its type, whether it’s estimated, and the release it shipped in.

04Track

One view of every request.

Work lists each request with its status, price, tasks, hours and messages. Group it by release to see what went out in each version, save the view, or export it.

05Control

One switch turns it all off.

Every agent has a charter, a settings file, a run history with cost, and a mailbox. Any agent can be paused. Power off refuses every agent call and kills any run in flight, and nothing turns itself back on.

06Bill

Invoices line up with releases.

Each invoice line names the release and change it pays for, with hours and amount. The list shows the effective hourly rate per invoice and flags the ones that fall below target.
